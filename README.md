# AutoGTG

PWA + WhatsApp platform connecting Kashmir vehicle owners with vetted garages for repairs, detailing, and denting/painting.

## Repo layout

```
autogtg/
├── apps/
│   └── user-pwa/      # Next.js 14 — user-facing PWA (in progress)
├── packages/          # shared packages (added when needed)
└── pnpm-workspace.yaml
```

## Run

```bash
pnpm install
pnpm dev
```

User PWA boots at <http://localhost:3000>.
